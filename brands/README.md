# Brand kits

One folder per brand: `brands/<brand-name>/`

- `brand.json` – colours, fonts, logo paths, voice, default CTA, voiceover voice, music mood, motion style (copy `_template/brand.json`).
- `assets/` – logo files (SVG preferred), font files, approved product photos.

Every video in `videos/` names its brand in `meta.json` and pulls colours, fonts, logo and CTA from here, so all videos for a brand look and sound consistent.
